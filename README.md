# 🤖 AI Study Buddy

Upload your PDF notes and get AI-powered Summary, Quiz & Answers.

## Features
- 📝 Chapter Summary
- 🎯 MCQs Quiz Generator  
- 💬 Ask Anything From Your Notes

## How to Run
1. Clone this repo
2. Install: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`
4. Enter your Gemini API Key

## Tech Used
Python, Streamlit, Google Gemini AI
